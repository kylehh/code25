## 1 Memory branch
Engram is actually a word invited by [Ricard Semon](https://en.wikipedia.org/wiki/Richard_Semon), who created engram(记忆痕迹) and ecphory.
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/richard.png) 
and you can actually view the engram cells from this [Science paper](https://www.science.org/doi/10.1126/science.aaw4325)
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/engram.png) 
Let's take a look at papers on LLM memories
1. Facebook 2019 - Language Models as Knowledge Bases
- KNN was used as KB in the traditional ML and LM is actually KB 
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/kb.png) 
2. Google 2020 - T5 作为 Knowledge Base
- Model can "look up information" stored in the parameters
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/t5.png) 
3. 2021 - Transformer FFN 层是 Key-Value Memory
- Critical [paper](https://arxiv.org/pdf/2012.14913) starting FFN as KV memory. 
- $FFN(x) = f(x * K^T)*V$ is a confusing formula here, isn't it self-atten?
- Key multiplication get memory coefficient
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/kvm.png) 
4. Microsoft 2022 - Knowledge Neurons
- Active neurons store knowlege and are referred as KN 
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/kn.png) 
- $FFN(H)=Gelu(HW_1)W_2$, here Hidden H is the concatentation of all attention heads
- $Self_Atten(x)=softmax(Q*K^T)V$, this makes more sense
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/ffn.png) 
5. Concept depth concept introduced in the following paper
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/cd0.png) 
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/cd.png) 
6. Facebook 2019 - Product Key Memory (PKM)
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/pkm.png) 
- K nearest neightboards used to find keys for each query
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/pkm.png) 
- product key method is split keys due to large key size
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/pkm1.png) 
7. Meta - Memory Layer 扩展到 128B 参数
- ML is scalable 
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/ml0.png) 
- Adding **gating** for control on tops of PKM
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/ml.png) 
8. DeepMind 2022 - Retrieval-Enhanced Transformer (RETRO)
- Instead of using parameters as KN, external docs can be used as KN, smiliar to RAG
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/retro0.png) 
- CCA(Chunked Cross Attention) was introdued here. similar to N-gram in Engram
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/retro.png) 
9. Google 2023 - External Memory 提升模型能力
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/em0.png) 
- additional parameters for input representation (Ngram)
- expert function (MoE)
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/em.png) 

## 2 N-Gram branch
Original bag of words is lacking words orders, and N-gram can be used to improve that
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/2gram.png) 
1. Google 2022 - N-Grammer：用 N-gram Embedding 增强 Transformer
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/ngram0.png) 
- Codebook ID is used to reduce vacab size, which is V^2 in case of 2-gram.
- k-means cluster is uesd to reduce dim. 
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/ngram.png) 
2. Google 2025 - Scaling Embedding Layer
- Introduced f-gram, frequently occuring n-grams
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/scale0.png) 
- The embedding table can be precomputed and offload to disk! 
![Alt text](/code25/assets/images/2026/26-01-23-engram_files/scale.png)

- A gating mechanisium is similiart to Q/K/V memory mathcing and weighted sum
